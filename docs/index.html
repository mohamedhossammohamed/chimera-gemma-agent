Pipeline — why each piece exists

OpenMed CPU 0GB • 8ms
Fixes: stored psav ρ0.465 drift (mean 3.7 max 117) → recompute PSADT=ln2/k*12, PSAV=Σ(t-t̄)(v-v̄)/Σ(t-t̄)²; V-shaped 89 cases flag; pirads NA→null; psad drift 24 cases; family 7→3; bx_isup 0 vs null; dre sentence cT; cT2/cTx→cT2a/None; MRI winsorize -31.7→-22; prost [n,960] mean-pool.
Gemma Client • 18 RPM
Reads OPENROUTER_API_KEY from env, never file. Token bucket 18/min, exponential backoff on 429, 60s timeout, JSON mode, mock fallback. No sk-or- in repo. 5-ARI×2 PSA correction before prompt.
Gated Fusion • 6ch
Handles 0% channels: Task1 0% biopsy, Task3 0% trend, 8 missing MRI → zero + gate 0. Site z-norm per mri_hospital (LUMC -0.35, VUmc -0.44, Gelderse -0.03) — fixes PC1 79% collapse. Fused dim 16, L2 scaled.
PyCox Head • censored
Discrete hazard 10 bins, KM S(t)=Π(1-d_i/n_i) Greenwood, C-index, risks from capra_s 0.12 + psad 0.3 + pirads 0.05. T3 19/56, early 5 ≤1.8mo. Mean risk 0.847.
